# 📄 DocAI

### AI-Powered Document Analysis & Question Answering

DocAI is an intelligent document-analysis prototype that allows users to upload PDF documents, extract their text, inspect document statistics, and ask natural-language questions about the uploaded content.

The project demonstrates a modular workflow for document processing and AI-assisted question answering.

---

## 🚀 Features

- 📄 PDF document upload
- 🔍 Automatic text extraction
- 📊 Document statistics
- 📝 Extracted-text preview
- 🤖 Natural-language document questions
- 🎯 Relevant sentence retrieval
- 💡 AI-style document answers
- 🖥️ Interactive Streamlit interface
- 🧩 Modular document-processing architecture
